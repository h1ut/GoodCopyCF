# GoodCopyCF

Расширение для браузера, которое чинит копирование условий задач на [Codeforces](https://codeforces.com).

*Browser extension that copies Codeforces problem statements with LaTeX formulas intact.*

## Зачем это нужно

Если выделить условие на Codeforces и нажать Ctrl+C, формулы ломаются: дроби, степени и индексы превращаются в кашу.

| | Что попадает в буфер |
|---|---|
| На странице | среднее значение (a₁ + a₂ + … + aₙ) / n, где 1 ≤ n ≤ 2 · 10⁵ |
| Без расширения | `среднее значение a1+a2+…+ann, где 1≤n≤2⋅105` |
| С расширением | `среднее значение $\frac{a_1 + a_2 + \ldots + a_n}{n}$, где $1 \le n \le 2 \cdot 10^5$` |

С GoodCopyCF условие можно сразу вставить в ChatGPT, Claude, Obsidian, Notion или любой редактор Markdown, и формулы останутся формулами.

## Как пользоваться

Никак по-особенному: выделите текст на Codeforces и нажмите Ctrl+C. Кнопок и настроек нет.

## Что копируется

- **Формулы** — как исходный LaTeX в долларах: `$a_i$`, `$1 \le t \le 10^4$`. Выключные формулы — в `$$...$$`.
- **Жирный текст** — как `**текст**`.
- **Списки** — с маркерами `- ` или номерами.
- **Примеры** входных и выходных данных — без изменений, их можно вставлять в файл или терминал.
- **Шапка задачи** — по строке на каждое ограничение: `ограничение по времени на тест: 1 секунда`.
- **Старые задачи без MathJax** — степени и индексы сохраняются: `10^9`, `a_i`.

Ещё несколько деталей:

- Если формула выделена частично, она копируется целиком.
- Расширение работает в условиях задач, постах и комментариях.
- В полях ввода (например, в редакторе кода) и на остальных частях сайта копирование остаётся обычным.
- Если в расширении что-то пойдёт не так, сработает обычное копирование браузера.

## Установка

### Firefox

Нужен Firefox 127 или новее.

1. Скачайте репозиторий: зелёная кнопка **Code → Download ZIP**, затем распакуйте архив.
2. Откройте `about:debugging#/runtime/this-firefox`.
3. Нажмите **«Загрузить временное дополнение»** и выберите файл `manifest.json` из распакованной папки.
4. Обновите открытые вкладки Codeforces.

Временное дополнение пропадает после перезапуска Firefox, его придётся загрузить заново.

### Chrome и другие браузеры на Chromium

1. Скачайте и распакуйте репозиторий, как описано выше.
2. Откройте `chrome://extensions` и включите **«Режим разработчика»**.
3. Нажмите **«Загрузить распакованное расширение»** и выберите распакованную папку.
4. Обновите открытые вкладки Codeforces.

> **О поддержке браузеров.** Автор пользуется расширением только в Firefox. В Chrome оно должно работать, потому что код общий для обоих браузеров, но там оно проверено гораздо меньше. Если в Chrome что-то не так, заведите issue.

## Приватность

- Работает только на `codeforces.com`.
- Не запрашивает никаких разрешений.
- Не собирает данные и ничего не отправляет в сеть.
- Код не минифицирован: всё, что делает расширение, лежит в трёх файлах в папке `src/`.

## Известные ограничения

- Картинки из условия не копируются.
- Символы Markdown в обычном тексте не экранируются, поэтому два жирных фрагмента подряд дадут `**x****y**`.
- Ячейки таблиц разделяются пробелом, а не табуляцией.
- Если в меню MathJax переключить способ отрисовки на MathML, формула скопируется дважды.

## Нашли ошибку?

Заведите [issue](https://github.com/h1ut/GoodCopyCF/issues): приложите ссылку на задачу и то, что оказалось в буфере обмена.

## Для разработчиков

Нужен Node.js 22.2 или новее.

```
npm install
npm test        # тесты
npm run build   # архив dist/goodcopycf-<версия>.zip для магазинов расширений
```

Как устроен код:

- `src/serialize.js` — превращает фрагмент страницы в текст.
- `src/selection.js` — превращает выделение во фрагмент и решает, вмешиваться ли.
- `src/content.js` — обработчик события копирования.

Перед новой публикацией поднимите `version` в `manifest.json` и `package.json`.
